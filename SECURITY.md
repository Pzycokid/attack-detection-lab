# Security Policy

## Intended use

This repository is a **defensive** detection-engineering reference. It contains ATT&CK technique
documentation and Sigma detection rules only. It does **not** contain exploit code, malware, or
offensive tooling.

Any simulation referenced here must be run only inside an **isolated lab you own**, using the
published [Atomic Red Team](https://github.com/redcanaryco/atomic-red-team) tests. Never run
adversary simulations against systems you do not own or lack written authorisation to test.

## Reporting an issue

If you spot an error in a detection rule or writeup, please open an issue, or email the author.
